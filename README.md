# 夜航 Nightsail

Android 自律锁机 App：睡眠锁 + 番茄钟 + 禅定模式，一套锁机引擎，三个入口。
免费、无内购、无广告、无账号，数据不出机。

## 状态

M1 开发中：锁机引擎（无障碍服务 + 原生锁屏 + 前台服务 + 精确闹钟）+ 最小 Flutter 测试壳。
当前里程碑验收标准：**OPPO ColorOS 真机连测 3 晚不掉锁**。

## 模块架构（高内聚、低耦合）

```
android/
├── app/          Flutter 宿主 + 极薄 MethodChannel/EventChannel 桥
├── engine/       纯 Kotlin 锁机引擎：零 Flutter 依赖、零网络依赖
│                 状态机（唯一真相源）· 无障碍感知 · 闹钟调度 · 白名单策略
└── lockscreen/   原生锁屏 UI：零业务逻辑，只渲染引擎状态
```

纪律：

- engine 不知道 Flutter 存在，不知道网络存在
- 策略全部是纯函数，可单测
- comm（问责审批通讯层）后续作为独立模块加入，是**唯一**允许联网的模块；
  引擎对它只发本地事件，断网时优雅降级为本地验证码模式

## 构建

需要本机安装 Flutter SDK（3.24+）与 Android SDK（compileSdk 34）。

```bash
flutter pub get
flutter build apk --release --split-per-abi   # 单 ABI ≤ 15MB
```

真机调试（推荐，锁机功能在模拟器上意义不大）：

```bash
flutter devices            # 确认 OPPO 已连（需开 USB 调试）
flutter run --release      # release 模式行为更接近真实
```

## 真机验收清单（M1）

1. `flutter run --release` 装上后，先按引导完成无障碍授权
2. 测试壳点「睡眠锁」→ 锁屏页弹出
3. **从锁屏页打开微信** → 能打开；**从桌面打开抖音** → 被拉回锁屏
4. 按返回键 → 无效
5. 下拉通知栏 → 已被禁用（设备管理员生效时）
6. 点「模拟完成」→ 解锁
7. 静置一晚 / 息屏一小时 → 再亮屏，锁机仍生效

## ColorOS（OPPO）必做设置

系统限制无法程序化修改，首次使用请按引导完成（设置 → 应用管理 → 夜航）：

| 项目 | 路径 | 作用 |
|---|---|---|
| 自启动 | 应用信息 → 自启动管理 | 允许 |
| 后台运行 | 应用信息 → 电池 → 允许后台运行 | 禁止电池优化 |
| 任务锁定 | 最近任务 → 下拉夜航卡片 → 锁定 | 防一键清理 |
| 后台弹出界面 | 应用信息 → 权限管理 | 允许（锁屏弹窗前提） |
| 无障碍 | 设置 → 无障碍 → 夜航 | 引擎感知层（若提示"受限制的设置"：开发者选项关闭"禁止权限监控"，或执行 `adb shell appops set app.nightsail ACCESS_RESTRICTED_SETTINGS allow`） |

## 诚实的限制

- ROOT 设备不提供防御承诺
- 用户手动撤销无障碍权限 = 锁机失效（设置页有权限体检，统计页诚实记录"防护中断"）
- ColorOS 存在熄屏回收无障碍服务的报告（见 dont-kill-my-app），引擎已做存活心跳检测，丢失即提醒
- 不替换、不屏蔽系统锁屏：夜航锁屏叠加在系统 Keyguard 之上，只约束行为，不降级安全
